	extbf{Arquitectura general del sistema (explicación)}

Implementación con enfoque edge processing.

La solución involucra un enfoque que distribuye los procesos en los dispositivos móviles, para ello se contempla el desarrollo de una aplicación nativa en Android sobre la implementación en aplicaciones web progresivas (PWA), por el nivel de integración con el hardware.

Dentro de la aplicación se gestionarían diferentes servicios o módulos como lo son:
\begin{itemize}
    \item La ejecución del LLM
    \item Gestor de notificaciones
    \item Gestor de bases de datos
    \item API de conexión con el servidor centralizado
\end{itemize}
En el desarrollo se contempla la implementación de 2 bases de datos, una local y otra centralizada. Es importante diferenciar los propósitos de cada una; la base local recolectaría información sobre las interacciones del usuario de manera estrictamente local en conformidad con la Ley Federal de Protección de Datos Personales en Posesión de los Particulares (LFPDPPP) para la privacidad del usuario.

	extbf{Tecnologías contempladas en la propuesta}

	extbf{Pruebas de desempeño de identificación en LLMs base (entorno de pruebas)}: se contempla el uso de técnicas de \textit{prompt engineering} para maximizar la capacidad de modelos de lenguaje (LLM) en la tarea de clasificación de mensajes sospechosos.

Ollama: para ejecutar modelos localmente en el entorno de pruebas.

Jupyter: de Anaconda para automatizar la comunicación con el modelo desde Python hacia Ollama.

	extbf{Implementación del lado del servidor}

PostgreSQL: sistema de gestión de bases de datos relacional utilizado para almacenar registros de conversación procesados, configuraciones personalizadas por usuario y resultados de inferencia.

Django: framework web de alto nivel en Python, empleado para construir las APIs que permiten la comunicación entre la aplicación de mensajería y el servidor.

Azure o Ngrok: según el entorno de despliegue, el servidor puede ser alojado bajo un esquema on-premise mediante túneles seguros con Ngrok, o bien, mediante una infraestructura como servicio (IaaS) en la nube a través de Microsoft Azure, lo que brinda escalabilidad y disponibilidad remota en entornos reales.

	extbf{Aplicación de Android}: El sistema de detección se integra en una aplicación móvil desarrollada con Android, permitiendo análisis de mensajes directamente en el dispositivo del usuario.

LiteRT (TensorFlow Lite): tecnología que permite ejecutar modelos de lenguaje previamente ajustados en dispositivos Android, sin necesidad de conexión a internet o procesamiento en la nube. Esta herramienta es clave para el cumplimiento de principios de privacidad y para brindar respuestas en tiempo real.

Android Studio: entorno de desarrollo integrado (IDE) utilizado para construir la interfaz de usuario, lógica de comunicación con el modelo y el servidor, y todas las funcionalidades necesarias para una aplicación de mensajería segura.

\subsection{Lista de requerimientos funcionales}

\begin{itemize}
    \item El sistema debe permitir enviar y recibir mensajes
    \item El sistema debe tener inicio de sesión y creación de cuentas
    \item La clasificación debe activarse mediante el trigger “Se recibió un mensaje dentro del sistema de mensajería”.
    \item Evaluar diferentes enfoques mediante pruebas para medir el rendimiento de la inferencia del llm al realizar la tarea de clasificación del tipo de estafa y determinar el enfoque a proceder balanceando presupuesto reducido y un desempeño mínimo requerido para el requerimiento de “alertar al usuario en un tiempo pertinente para no caer en la estafa, lo más cercano al tiempo real”, los enfoques a evaluar son (refinamiento con prompt engineering o ajuste fino “fine tuning” involucrando un entrenamiento)
    \item La aplicación debe tener la opción de desactivar filtro (considerar también para las practicas, tener siempre un dispositivo que envia los mensajes sospechosos)
    \item Llevar un historial de mensajes clasificados como potencialmente peligrosos, incluyendo hora, usuario involucrado y tipo de amenaza detectada.
\end{itemize}
