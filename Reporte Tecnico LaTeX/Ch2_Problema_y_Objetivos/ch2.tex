\section{Límites y Alcances}
\subsection{Límites}

\begin{itemize}
    \item El presente proyecto no contempla en su diseño un enfoque de arquitectura RAG que otorgue alguna funcionalidad de software que actualice el contexto del modelo largo de lenguaje con neologismos, Eufemismos o jergas emergentes en la cultura de internet.

    \item El proyecto no contempla la creación de información destinada a cadena de custodia.

    \item El diseño de la aplicación de mensajería no contemplara la funcionalidad de chat grupal, será implementado únicamente para comunicación uno a uno.

    \item A lo largo del proyecto se contemplaran modelos largos de lenguaje con rangos de escala de entre 0.5 billones y 8 billones de parámetros, debido a características del sistema como lo son la clasificación en tiempo síncrono y el balance con hardware limitado.

    \item El presente proyecto no contempla el entrenamiento o ajuste fino de los pesos de los modelos largos de lenguaje.

    \item Este proyecto no incluye procesamiento de imagen ni de audio se trabajara únicamente con contenido escrito.
\end{itemize}


\subsection{Alcances}

\begin{itemize}
    \item Se contempla realizar refinamiento de una colección de modelos largos de lenguaje a través de técnicas de prompting y documentos con ejemplos de catfishing y sextorsión reales y sintéticos.

    \item Dentro de la investigación se efectúa la recolección de mensajería fraudulenta para fines de etiquetado y síntesis de datos \cite{SynthDataByIbm} se contempla el anonimato de los actores.

    \item A lo largo del proyecto se contempla medir y comparar el desempeño en la tarea de la clasificación por parte de cada modelo largo de lenguaje bajo 3 técnicas de prompting (zero-shot, one-shot y few-shot) las ultimas dos con datos reales y sintéticos.

    \item En esta investigación se contemplaran únicamente las estafas catfishing y sextorsión ambas por su relación directa y dependencia mutua en la mayoría de casos. \cite{To_pay_or_not_to_pay} % Esta fuente es muy textual

    \item El presente trabajo contempla el diseño de una aplicación web de mensajería instantánea
\end{itemize}

\section{Justificación del proyecto} 
% Proyecto de ing: ¿Que problema resuelve este proyecto?, ¿para quien será de utilidad?, ¿quien se ve beneficiado?, ¿qué  ventajas tiene con respecto a otros proyectos parecidos?

Este proyecto es un esfuerzo destinado a afrontar las estafas en línea dentro de sistemas de mensajería instantánea, con un enfoque particular en modalidades como el catfishing y sextorsión. Su utilidad práctica radica en proveer un entorno de mensajería que, mediante el análisis de carácter semántico efectuado a las conversaciones, pueda alertar de manera oportuna a los usuarios antes de convertirse en víctimas de este tipo de fraudes. De esta manera, el beneficio está orientado a personas de cualquier edad y género que utilicen sistemas de mensajería instantánea, fundamentándose en la prevención. La principal ventaja de esta propuesta, en comparación con las investigaciones que conforman el actual estado del arte, recae en el enfoque de solución pues, mientras los trabajos existentes se orientan principalmente a evaluar la efectividad o aplicabilidad de los modelos largos de lenguaje en la identificación de estafas, este proyecto propone el diseño de una solución web, la cual, mediante el uso de modelos largos de lenguaje, permita concebir un sistema de mensajería orientado a la prevención de fraudes.
