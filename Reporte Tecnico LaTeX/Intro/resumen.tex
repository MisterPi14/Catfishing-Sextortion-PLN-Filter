\chapter{Resumen}
El presente proyecto presenta el diseño de un sistema de mensajería web que integra funcionalidades de detección de catfishing y sextorsión asistida mediante aprendizaje profundo aplicado a las conversaciones dentro de la plataforma, con el propósito de lograr un alertamiento oportuno a los usuarios y así promover la prevención. Este proyecto está delimitado al idioma español, se plantea la utilización de modelos largos de lenguaje con refinamiento mediante las técnicas de prompting: one-shot, zero-shot y few-shot como elemento clasificador de contenido escrito.
El proyecto de igual manera contempla la generación de datos sintéticos y recolección de ejemplos de catfishing y sextorsión reales, adicionalmente se contemplan pruebas y comparación de desempeño de modelos largos de lenguaje con una escala máxima de 8 billones de parámetros.

\vspace{1.0cm}
\textbf{Palabras clave:} Aprendizaje profundo, Catfishing, Clasificación, , LLM, Sextorsión


\chapter{Abstract}
This project presents the design of a web messaging system that integrates catfishing and sextortion detection functionalities assisted by deep learning applied to conversations within the platform, with the purpose of achieving timely user alerting and thus promoting prevention. This project is delimited to the Spanish language, proposing the use of large language models with refinement through prompting techniques: one-shot, zero-shot and few-shot as a written content classifier element.
The project equally contemplates the generation of synthetic data and collection of real catfishing and sextortion examples, additionally performance testing and comparison of large language models with a maximum scale of 8 billion parameters are contemplated.

\vspace{1.0cm}
\textbf{Keywords:} Catfishing, Classification, Deep Learning, LLM, Sextortion
